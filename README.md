# CATCH TRUMPET - Epstein Files Edition

A Flappy Bird-style game where you navigate through the actual Epstein Files, collecting redacted names while avoiding document references.

## How to Play

1. Open `index.html` in a web browser
2. Press **SPACE** or **CLICK** to fly the 🔍 (magnifying glass)
3. **AVOID** the white text words (obstacles)
4. **COLLECT** the black ████████ redactions to reveal hidden names
5. Every 10 files collected, an angry Trump appears - **DODGE HIM!**
6. Click "BONDI TESTIMONY" button to play audio (requires `bondi_testimony.mp3`)

## Game Features

- 🔍 **Magnifying Glass** - You play as a detective seeking the truth
- 📄 **Authentic FBI/DOJ Documents** - Background features real case file styling
- 💥 **Exploding Redactions** - Touch black boxes to reveal real names with special effects
- 🤬 **Trump Encounters** - Boss fights every 10 files collected
- 🕯️ **Memorial** - Honors the brave survivors who came forward
- 🎵 **Audio** - Pam Bondi congressional testimony (add your own audio file)

## Data Accuracy

All names are sourced from:
- Epstein Flight Logs (1,700+ documented flights)
- Court documents (Giuffre v. Maxwell)
- DOJ Epstein Files releases
- Verified public testimony

Verified names include: Prince Andrew, Bill Clinton, Donald Trump, Alan Dershowitz, and others documented in official records.
